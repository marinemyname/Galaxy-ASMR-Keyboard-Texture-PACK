# marinemyname Galaxy ASMR Keyboard Texture Pack

A Minecraft **Bedrock Edition** resource pack that replaces walking sounds with keyboard click sounds.

Made by **marinemyname**.

## Sound Versions

This pack includes six selectable keyboard-sound versions:

| Version | Source |
|---|---|
| **KBDFans Tofu65** | Recorded by marinemyname |
| **AULA F75 (Keycap Mod)** | Recorded by marinemyname |
| **Creamy Sound 2** | From oSkullo’s pack |
| **Creamy Sound** | From oSkullo’s pack |
| **Mechanical Sound** | From oSkullo’s pack |
| **Deep Thock** | Pitched-down version of Creamy Sound |

## Download

Download the latest `.mcpack` from the  
[Releases page](https://github.com/marinemyname/Galaxy-ASMR-Keyboard-Texture-PACK/releases).

## Installation

1. Download the latest `.mcpack` file.
2. Open the file. Minecraft Bedrock should import it automatically.
3. Go to **Settings → Global Resources → My Packs**.
4. Select **marinemyname Keyboard Sounds**.
5. Click **Activate**.
6. Open the pack’s settings and choose your preferred keyboard sound version.

## Manual Installation

If `.mcpack` does not open automatically:

1. Download the `.zip` release.
2. Extract it into your Bedrock `resource_packs` folder.
3. Restart Minecraft.
4. Go to **Settings → Global Resources → My Packs** and activate the pack.

## Compatibility

- Minecraft Bedrock Edition
- Designed mainly for PC / Windows players
- Works in worlds and servers that allow resource packs
- Does not require Java Edition, OptiFine, Fabric, Forge, or NeoForge

## Known Limitation

The keyboard sound may not replay immediately after a very short pause or single step. This is related to how Bedrock handles repeated step-sound events.
